# 手寫字體．古詩展示

一個用於展示學生手寫字體與電腦字體差異的網頁 Demo

## 功能

* 學生字體選擇
* 支援 `.ttf`、`.otf`、`.woff`、`.woff2` 字體
* 可直接上傳字體進行即時展示
* 即時輸入展示名稱
* 手寫字體與電腦字體並列比較
* 手寫字體資料以紅色顯示，機器生成字體以藍色顯示
* 可開啟或關閉字體分類
* 可調整詩詞字體大小與粗細
* 支援《長恨歌》與《琵琶行》
* 支援紙本與夜色背景
* 支援背景音樂播放

## 使用方式

將專案下載後，以瀏覽器開啟網頁

學生字體資料由 `students.json` 載入，字體檔案放置於對應的資料夾

主要檔案：

```text
font-demo-web/
├── index.html
├── students.json
├── handwriting.txt
├── background.mp3
├── ttf/
└── img/
```

## 學生字體格式

`students.json` 使用以下格式：

```json
[
    {
        "name": "學生姓名",
        "font": "ttf/Font_XXXXXXXXX.ttf"
    }
]
```

## 展示內容

目前提供兩首古詩：

* 長恨歌
* 琵琶行

可透過頁面上的功能切換詩詞、學生字體、背景及展示設定

## 背景圖

背景圖片使用 Gemini 生成，並依照不同詩詞使用不同背景圖片
